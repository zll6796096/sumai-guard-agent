離れて暮らす親の家で気になる場所を、写真1枚から確認するためのアプリです。
写真に写っている範囲の、転倒・つまずき・滑りにつながる可能性がある箇所を赤枠で示し、次にできることを3つの相談先に分けて整理します。

【できること】
・カメラまたは写真ライブラリから写真を1枚選択
・写真に見える注意箇所を赤枠で確認
・見えている根拠と、写真だけでは判断できないことを確認
・次の対応を「家族で今日できること」「ケアマネ・福祉用具に相談」「専門施工・現地確認」に整理
・写真を含まない日本語の安全アドバイスPDFを端末上で作成・共有

【プライバシー】
写真を送信するたびに、Google Cloud RunとGoogle LLCのGeminiで処理されることを説明し、同意を確認します。送信前にEXIFを削除します。写真、結果画像、PDF、利用履歴をSumaiGuardのデータベースやアカウントへ永続保存しません。Firebase App CheckとApple App Attestを不正利用対策に利用します。通常のCloud Logging運用ログは30日間保持されますが、写真、解析結果、PDFの内容は記録しません。

【大切な注意】
本アプリが示すのは、写真に見える範囲の一般的な注意点です。危険を見落とす場合があり、住まいの安全を保証しません。医療、介護認定、保険、法令適合、正確な寸法、見積もり、施工の判断は、ケアマネジャー、福祉用具専門相談員、医療・施工などの専門家へご相談ください。
